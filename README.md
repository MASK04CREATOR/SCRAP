# SCRAP X – deploy free (no install needed, browser only)
1. github.com → New repository (Public) → "Add file > Upload files" → upload app.py, requirements.txt, packages.txt.
2. share.streamlit.io → sign in with GitHub → New app → pick repo, branch main, file app.py → Deploy.
3. App settings > Secrets (for chat): GEMINI_API_KEY = "your-free-key"
4. Share the app URL with teammates.
